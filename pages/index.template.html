What this compares

Both frames are built from the same BlockNote source and the same two-paragraph fixture. The Before frame is the unmodified baseline; the After frame can be switched between the combined patch and each isolated file. This shows which change fixes focus and which fixes activation.

The problem

With the side menu showing and the caret in a block, Tab can focus a cloned Add block button from the closing transition. That copy has no React handlers; Enter and Space do nothing, and about 250 ms later it is removed and focus falls to the document body. The live Add block button also ignores Enter and Space because its click handler is on the icon.

Steps to replicate

  1. Hover the first paragraph in either frame so the side menu appears, then click it to place the caret.
  2. Press Tab. Compare where focus lands in Before and After; the focus status reports the active control inside the frames.
  3. With the side menu showing, focus Focus after editor, press Shift+Tab twice to reach Add block, then press Enter and Space.
  4. Use the theme and width controls; test the keyboard separately in each frame. Tab and Enter are not mirrored.

Limits and provenance

  • Even “both fixes” is partial: it prevents focus loss and fixes activation, but the side menu is still only revealed by pointer hover. Keyboard-only discovery needs a maintainer decision.
  • Only the default Mantine UI and Chromium were exercised. Ariakit, shadcn, Firefox and Safari are unverified; no human screen-reader session was recorded.
  • The proposed upstream regression test is in the repository but has not been run because BlockNote requires its browser suite to run in Docker.
  • Static bundles are prebuilt from upstream 9cb988ff94b60979bbbc62b0ded5cf62fdac88c8 plus local fixture 4611ae1b and committed to pages/before, pages/after, pages/after-inert and pages/after-activation; the Pages workflow assembles the page but does not rebuild BlockNote. BlockNote remains MPL-2.0; see LICENSE-BlockNote.txt.
  • No upstream BlockNote PR was opened. This is a local experimental comparison, not a conformance claim.
